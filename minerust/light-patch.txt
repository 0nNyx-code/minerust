+# LIGHT Shaders — NolModal Tech x Bagus Dev (Lite)
+
+Turunan LIGHT Shaders 1.9.0.1 (Chocapic13's Shaders edit), dibundel sebagai
+shader default di fork "NolModal Tech x Bagus Dev" untuk Horizon Android.
+
+Kredit asli: Chocapic13 dan pembuat LIGHT Shaders. Tidak untuk dijual.
+
+## Yang diubah dari LIGHT asli
+
+Perbaikan visual (sudah ada di paket HorizonFix):
+- Alpha cutout rumput/daun/bunga benar, tidak lagi jadi blok hijau raksasa.
+- Kaca tidak lagi dianggap air.
+- final.fsh valid GLSL 120.
+- Output shadow dirapikan.
+
+Optimasi Lite (FPS, tampilan tetap):
+- Shadow map 512 (dari 1024) dan jarak bayangan 70 blok.
+- TAA dimatikan (hemat satu pass penuh, tepi tetap tajam).
+- gcolor RGBA8, bukan RGBA16: bandwidth turun di tile GPU.
+- Godrays 4 sampel (dari 7), jarak sampel dikompensasi.
+- Refleksi air di-raytrace maksimal 10 langkah (dari 16); refleksi,
+  riak air, caustics, awan bergerak, dan bayangan tetap aktif.
